# JUSHQIN DIGITAL — Personal Brand Platform

Premium personal brand website + admin CMS for **JUSHQIN**.

## Features

- **5 Public Pages**: Home, About, Projects, Skills, Contact
- **6 Real Projects** with live URLs
- **Admin Login**: `jushqin2013` / `222222`
- **Full CMS Dashboard**: Profile, Projects (CRUD), Skills (CRUD), Messages, Appearance
- **localStorage** data persistence
- **Dark / Light theme**
- **Responsive** design
- Pure HTML + CSS + Vanilla JS (no frameworks)

## How to run

1. Open the folder in VS Code
2. Install "Live Server" extension
3. Right-click `index.html` → Open with Live Server

Or open `index.html` directly in a browser (some features work better with a local server).
